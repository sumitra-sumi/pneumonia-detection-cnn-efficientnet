# Pneumonia Chest X-ray Classification using Deep Learning

This project uses CNN and EfficientNetB0 to classify chest X-ray images as NORMAL or PNEUMONIA.

## Features
- CNN baseline model
- Transfer learning using EfficientNetB0
- Fine-tuning
- Data augmentation
- Class imbalance handling using class weights
- Confusion matrix and classification report
- Heatmap visualization
- Misclassification analysis

## Final Results
- Final Accuracy: 91%
- High recall for pneumonia detection

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Chest X-ray dataset used for pneumonia detection.
